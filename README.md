## 🚀 What I've shipped

| | Project | What it does |
| :-: | --- | --- |
| ⚖️ | **[Radiant Claims](https://radiantclaims.com)** | Platform for federal RECA compensation claims. Seven agents extract entities, sort documents and check each filing against federal rules, with flagged cases sent to staff. A four-tier OCR cascade picks the cheapest engine that can read each page. |
| 📚 | **[Knowlchemy](https://knowlchemy.com)** | Turns documents, video and audio into a searchable knowledge base. A five-stage pipeline grades every model answer before a user sees it, and RAG runs two ways in production. |
| 🎾 | **[DNKNG](https://dnkng.app)** | Pickleball app that scores live games by voice, in TestFlight beta with real users. On-device Whisper and game state stay the source of truth, so a misheard call never corrupts the game. |
| ⚡ | **Automation work** | Cut a founder's operational load from about 40 hours a week to 6 with n8n and LLM-assisted drafting. In daily use since 2024. |
